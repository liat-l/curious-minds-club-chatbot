# Curious Minds | צ׳אט חוגים

צ׳אט למרכז העשרה אחרי הלימודים. אפשר לבחור חוג, לשאול שאלות עליו, להחליף חוג באמצע שיחה ולפתוח שיחות שנשמרו גם אחרי אתחול Colab. חמשת החוגים הם אסטרונומיה, בישול, כדורגל, גאוגרפיה עולמית ותכנות בפייתון.

המחברת משתמשת ב־LangGraph לניהול מצב השיחה, ב־OpenAI לתשובות, ב־Supabase PostgreSQL לשמירה וב־Gradio לממשק בעברית.

## הפעלה ב־Google Colab

1. ב־Supabase פתחו פרויקט. לחצו על **Connect → Session pooler** והעתיקו את מחרוזת החיבור (פורט 5432). החליפו את מציין מקום הסיסמה בסיסמת מסד הנתונים. הטבלאות נוצרות אוטומטית בהפעלת המחברת. [הוראות חיבור של Supabase](https://supabase.com/docs/guides/database/connecting-to-postgres)
2. העלו את `club_chatbot.ipynb` ל־Colab. בסרגל **Secrets** הוסיפו `OPENAI_API_KEY` עם מפתח של פרויקט בעל גישה למודל ו־`SUPABASE_DB_URL` עם מחרוזת החיבור המלאה. הפעילו **Notebook access** עבור שני הסודות.
3. הריצו את תאי המחברת לפי הסדר. תא הבדיקה העצמאית שולח ארבע בקשות ל־OpenAI. אפשר לדלג עליו כאשר מפעילים שוב את הממשק.
4. בתא Gradio בחרו סיסמה זמנית. פתחו את הקישור מהפלט והתחברו עם המשתמש `curious-minds` והסיסמה שבחרתם.
5. בחרו חוג ושלחו שאלה. **שיחה חדשה** מנקה את המסך. תפריט **שיחות שמורות** משחזר את ההודעות ואת החוג הפעיל. לבדיקת ההתמדה, אתחלו את Colab, הריצו שוב עם אותם סודות ופתחו שיחה קודמת.

שמרו את קישור Gradio ואת סיסמת הכניסה לעצמכם. שימוש בממשק מאפשר גישה לשיחות שמורות וצורך את מכסת OpenAI שלכם. שמרו את מפתח ה־API ומחרוזת החיבור ב־Colab Secrets בלבד.
